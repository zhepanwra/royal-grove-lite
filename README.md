# royal-grove-lite

I build things, like @pretalx or @venueless. I run events, like @metarheinmain or @c3cashdesk.

处理日常小任务的工具

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/royal-grove-lite.git
cd royal-grove-lite
pip install -r requirements.txt
```
